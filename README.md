🌿 Cielo Roto Eco-Hotel & Mirador

Una landing page interactiva y moderna diseñada para el eco-hotel y mirador **Cielo Roto**. Permite a los usuarios explorar las instalaciones, consultar el clima del sitio, calcular la estadía y realizar reservas de forma rápida y sencilla.

---

🚀 Características Principales

* **Visualización de Instalaciones:** Galería interactiva y presentación del eco-hotel para los visitantes.
* **Consulta de Clima y Ubicación:** Información útil sobre las condiciones meteorológicas del lugar y mapas interactivos.
* **Calculadora de Estadía:** Funcionalidad para presupuestar el costo de la estadía según las noches elegidas.
* **Sistema de Reservas:** Formulario interactivo para agendar la estancia.
* **Asistencia Inteligente (IA):** Integración con la API de Google AI Studio (Gemini) para responder preguntas frecuentes y brindar asistencia a los huéspedes.
* **Conexión Directa:** Botones de acceso rápido a WhatsApp e Instagram para atención personalizada.

---

🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend / Lógica:** Java
* **Inteligencia Artificial:** Google AI Studio (Gemini API)
